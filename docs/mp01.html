Task 1: Data Acquisition

The Netflix’s data was acquired using the provided R function. The code downloads and combines different reports, covering the data between 2023 - 2026 to a single dataset - NETFLIX_DATA.

NoteView Data Acquisition Code 
#' Acquire Netflix What We Watched Reports
#' This function acquires and standardizes the Netflix data.

load_netflix_data <- function() {

  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)

  data_dir <- path("data", "mp01")

  if (!dir_exists(data_dir)) {
    dir_create(data_dir, showWarnings = FALSE, recurse = TRUE)
  }

  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )

  download_if_needed <- function(url, local) {
    if (!file_exists(local)) {
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    return(local)
  }

  NETFLIX_URLS |>
    map(read_html) |>
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |>
    map_chr(html_attr, "href") |>
    enframe("period", "url") |>
    mutate(
      path = path(data_dir, paste0(period, ".xlsx")),
      path = map2(url, path, download_if_needed),
      data = map(path, read_excel, skip = 3, na = "*"),
      data = map(
        data,
        \(x) x |> mutate(`Release Date` = as.Date(`Release Date`))
      )
    ) |>
    unnest(data) |>
    select(-url, -path) |>
    mutate(
      year = str_sub(period, 1, 4),
      half = str_sub(period, start = 6),
      period_start = make_date(year, if_else(half == 1, 1, 7), 1),
      period_end = make_date(
        year,
        if_else(half == 1, 7, 12),
        if_else(half == 1, 30, 31)
      )
    ) |>
    filter(!is.na(`Hours Viewed`)) |>
    mutate(
      live_event = !is.na(Runtime) &
        str_detect(Runtime, "\\d+:\\d+\\*"),
      clean_time = str_remove(Runtime, fixed("*")),
      Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))
    ) |>
    select(-clean_time) |>
    mutate(
      Runtime = coalesce(Runtime, mean(Runtime, na.rm = TRUE)),
      .by = Title,
      Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
      Title = str_remove(Title, " // .*"),
      Title = str_remove(Title, "[^[:ascii:]].*"),
      Title = str_trim(Title)
    ) |>
    filter_out(Title == "") |>
    select(
      year,
      period,
      period_start,
      period_end,
      Title,
      -half,
      Runtime,
      Views,
      `Hours Viewed`,
      `Release Date`,
      `Available Globally?`,
      live_event
    ) |>
    rename(
      title = Title,
      runtime = Runtime,
      views = Views,
      hours_viewed = `Hours Viewed`,
      release_date = `Release Date`,
      available_globally = `Available Globally?`
    ) |>
    mutate(
      year = as.integer(year),
      available_globally = available_globally == "Yes"
    )
}

NETFLIX_DATA <- load_netflix_data()

shows_vs_movies <- NETFLIX_DATA |>
  mutate(
    content_type = case_when(
      str_detect(title, regex("Season", ignore_case = TRUE)) ~ "TV Show",
      !is.na(runtime) & runtime > 180 ~ "TV Show",
      is.na(runtime) ~ "Unknown",
      TRUE ~ "Movie"
    )
  ) |>
  group_by(period, content_type) |>
  summarise(
    hours = sum(hours_viewed, na.rm = TRUE),
    .groups = "drop"
  ) |>
  group_by(period) |>
  mutate(share = hours / sum(hours)) |>
  ungroup() |>
  arrange(period, content_type)

Task 7: Corporate Strategy Memo

The conducted analysis reveals that Netflix’s shows generate most of the company’s viewing hours. As a next move, the company should diversify its portfolio. Specifically, Netflix should prioritize successful shows while also developing its own movie production.

TV Shows vs. Movies

A successful show can encourage viewers for more hours spent on the platform for other seasons and spin-offs, however, a successful movie can be more suitable for someone who is not ready for a double digit viewing commitment.

The analysis distinguished shows and movies by utilizing the length - more than 3 hours - and key words - Season - in the title. To avoid ambiguity, the entries with missing information were classified as “Unknown”.

Based on this classification, the shows accounted for 95% of total viewing hours in almost all reports. The movies accounted for 2.5–4%.

The first reporting period reveals an interesting observation. The shows in 2023H1 accounted only for 69.17% of viewing hours, movies for 2.88%, and unknown titles for 27.95%. This difference is probably related and associated with missing runtime information - titles with more than 3 hours of runtime. It does not really show any shift in viewing preferences. For this reason, the results should not be viewed as final or conclusive.

Recommendation: Netflix should continue investing and developing its original shows. Simultaneously, the platform should diversify its movie portfolio.

Shorter vs. Longer Content

The analysis reveals the dominance of longer content.

Titles with the duration of 1-2 hours account for only 0.97% of hours viewed. The entries with the duration of 30–60 minutes account for 0.26%, finally, the content with the duration of less than 30 minutes accounts only for 0.08%.

However, these findings do not prove that Netflix should stop producing shorter content. Shorter titles appeal to younger generation and customers who are unwilling to commit or have limited time.

Recommendation: Netflix should continue experimenting with shorter content given the popularity of TikTok, Instagram Reels, and short shows. The decision should not be solely made on the basis of viewing hours.

Strategic Recommendations for 2027 and Beyond

Netflix should incorporate a diversified portfolio of longer titles with shorter content.

Different shorter formats should be explored and tested, however, Netflix should not abandon its famous longer content.

Conclusion

Netflix’s reporting data only strengthens the position of longer content the platform provides to its clients. However, the shorter content should also be considered as a coplimenarty option.

For 2027, Netflix should uphold its longer content as the main asset while evaluating entering into shorter formats production. A comprehensive and diversified title portfolio can help Netflix preserve its dominance and penetrate the market even more.
